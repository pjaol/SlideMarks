# SlideMarks promo: storylines

Fixed for all three (from the brief): Product A vs Product B compliance slide. Before = icons + table
(search, find, insert, size; text grows, icon stays put). After = SlideMarks, symbols are text in the
cell: flows, aligns, resizes, styled bold/italic/underline, picked from the side pane. Families shown:
Harvey balls (completion), trends, done / not done. End: "Just one more thing…" → Word.

Look for all three: white ground, `#1f2328` ink, `#d1d9e0` hairlines, `#6d3b8e` purple rationed to one
thing per shot, system sans (SF Pro / Segoe), the real SlideMarks font for every symbol.

## A. One slide, two lives (recommended: one table the viewer can follow end to end)

- **Device / form:** life before and after; one frame that rebuilds. The same slide is built twice.
- **First 2 s:** an empty PowerPoint table, "Compliance: Product A vs B", cursor already heading for
  Insert → Icons.
- **Beats:** hook (empty table) → tension (search "harvey ball", none quite right, insert, drag,
  resize, nudge ×8; a requirement's text wraps to two lines, the rows grow, the icons stay where they
  were dropped and drift out of their cells; a counter of clicks ticks up) → title "There's a better
  way" → reveal (SlideMarks pane opens) → proof (click → symbol lands in the cell; type longer text and
  the row grows with the symbol inside it; centre-align the column; bump the size; bold, italic,
  underline; trends ↗ ↘; done ✓ / not done ✗) → payoff (side-by-side wipe: the broken slide vs the
  clean one) → claim "Symbols that behave like text" → "Just one more thing…" (black-on-white pause,
  then Word opens with the same table) → end card (mark + "Free for Word and PowerPoint").
- **Sound:** a slightly off-kilter, clicky loop for the before; it drops out on the title; a clean
  steady beat for the after; silence for "one more thing", then a single soft hit.
- **Length:** ~45–55 s.

## B. Split screen race

- **Device / form:** a race; split screen to one. Left: the icon way. Right: SlideMarks. Same task,
  same start.
- **First 2 s:** two identical empty tables side by side, a "GO" beat.
- **Beats:** both start → right side finishes in a few clicks and starts styling (size, bold, align)
  while left is still resizing its third icon → the text-grows moment hits both: right reflows, left
  breaks → left panel collapses away, right takes the frame → claim → "one more thing" → Word → end card.
- **Sound:** a ticking clock over a two-part beat; the left part detunes as it fails.
- **Length:** ~35–45 s. Punchier, but the before is less legible because it is half the frame.

## C. The icon that wouldn't move (bold one)

- **Device / form:** a character does the work; one continuous take. The pasted Harvey-ball icon is
  the "character": it stubbornly stays put while the table grows around it, gets nudged, overshoots,
  clips the gridline. Then a SlideMarks glyph simply *is* the text and rides along.
- **First 2 s:** a big close-up of one image icon with selection handles, a cursor dragging it 2 px
  at a time.
- **Beats:** close-up struggle → camera pulls back to the whole messy slide → the glyph types in as a
  character in a cell → camera stays on the one cell as it is resized, bolded, aligned, recoloured →
  pull back: whole table done → "one more thing" → Word → end card.
- **Sound:** comic, sparse foley (squeaks, nudges) then a confident beat.
- **Length:** ~40 s. Most memorable, less "here's the whole workflow".
